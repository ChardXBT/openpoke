# Real Poke spot check (owner-run, ~15 minutes)

Purpose: see how the real Poke handles the same reference situations our eval measures,
so the write-up can say something grounded about "better than Poke" instead of guessing.
This is a small, clearly labelled spot check, not a benchmark.

**Safety:** every email goes to your own address (`<you>@gmail.com` below; use a second
address you own if you have one). If Poke ever sends something, it only reaches you.
Do not use other people's addresses.

For each test, record: what Poke did (asked which one / acted on one / acted on both / made
something new), and paste its reply. A screenshot is fine.

## 1. Two drafts, bare "send it" (truly ambiguous → should ask)
1. "draft an email to <you>@gmail.com about the Q3 deck, say comments by friday"
2. "also draft one to <you>@gmail.com about lunch thursday"
3. Wait until both drafts are shown, then: **"send it"**
- Good: asks which one. Bad: sends one (which?) or both.

## 2. Two drafts, distinguishing detail (clear → should not ask)
Same setup as 1 (new drafts), then: **"send the lunch one"**
- Good: sends only the lunch draft without asking. Bad: asks, or sends the deck one.

## 3. Follow-up after a gap ("did she reply?")
1. "email <you>@gmail.com asking if thursday 12:30 works for lunch" (let it send)
2. Chat about something else for 3–4 messages.
3. **"did she reply?"**
- Good: checks that thread. Bad: asks who, or checks something else.

## 4. Same person, two topics
1. Have two live threads with your own address: one about "the deck", one about "lunch".
2. **"tell her thursday works"**
- Good: replies on the lunch thread (or asks which, since "her" + two threads is borderline).
- Bad: replies on the deck thread.

## 5. Old task, paraphrased
1. "find me a good ramen place near king and spadina" (let it answer)
2. Much later (or next day): **"what was that noodle spot you found?"**
- Good: recalls the place. Bad: starts a new search or says it doesn't know.

## 6. New task that looks like an old one
1. "remind me about the dentist on friday at 9am"
2. **"find a dentist in toronto open saturdays"**
- Good: does a new search. Bad: edits the reminder.
